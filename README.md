# MP3AgainstHumanity - Who needs Spotify?

Sitting on a train with no internet and a dead iPhone. All I have is a laptop, Python, and some MP3s. This script exists so I don’t have to listen to my own thoughts.

## Quick start

1. Put your audio files in `./songs` (supports `.mp3`, `.wav`, `.ogg`).
2. Run:

```
python play_music.py
```

3. Choose sequential or random.

## Controls

### Buttons

- `Prev` / `Next`: move through the playlist
- `Play` / `Pause`: toggle playback
- Progress bar: click to seek within the current track

### Keyboard

- `Space`: play/pause
- `Left` / `Right`: previous / next track
- `Enter`: play the top search result
- `Esc`: clear search

## Quick search

- Start typing to filter songs by title.
- Results update as you type.
- Click a result (or press `Enter`) to play it immediately.
